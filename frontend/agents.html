Agent Details

🔍

Monitor Agent

Continuously polls live flight status feeds. Detects three types of disruptions: cancellations (immediate), missed connections (using per-airport minimum connection time buffers), and major delays (exceeding tolerance thresholds). The detection algorithm uses real logic with no AI simulation.

Real Algorithm
⚖️

Decision Agent

Evaluates alternative flights against the cardmember's policy constraints: fare cap ($200 max delta for Platinum), cabin downgrade rules, maximum layover duration (180 min), and arrival delay cap (240 min). Uses a weighted multi-criteria scoring function to rank compliant options.

Real Algorithm
🎫

Execution Agent

Books the chosen alternative through injected airline and hotel API clients. Implements retry logic with exponential backoff for transient failures. Automatically syncs hotel check-in dates when flights shift arrival times. Real error-handling logic, mocked API transport.

🔔

Notification Agent

Composes human-readable notifications with all relevant details: original flight, disruption reason, new booking confirmation, and updated hotel dates. Delivers through a NotificationSender interface — production would use push notifications, SMS, or email.

Architecture Notes

The Deliberate Seam

Everything in app/ except data.py has no idea it's talking to mocks. The seam is intentional: a production build replaces MockAirlineClient with a real Amadeus/Sabre client and events_for_scenario() with a live feed subscription — nothing else changes.

API Endpoints

The backend exposes five endpoints: GET /itinerary for the current trip, POST /reset to restore the original, POST /simulate/{scenario} for a one-shot run, GET /stream/{scenario} for real-time SSE streaming, and GET /metrics for detection speed and success tracking.
